# Fixtures

`crashes.csv` holds 1,000 **synthetic** crashes, generated by `scripts/generate-fixture.ts`
(`pnpm fixture:generate`). The rows are made up, not taken from the dataset, so the file
carries no dataset license. They use the exact CSV format of the Kaggle US Accidents
dataset: the same headers, local wall-clock times in the `US/*` zone names, `True`/`False`
flags, and empty fields for missing values.

The generator is seeded, so it always writes the same file. The rows cover nine states
and 2016 to 2023, and include the cases the loader and API must handle:

- About 1% of rows have no `Timezone`, so their times load as `NULL`.
- Arizona rows use `US/Mountain`, but Arizona doesn't observe daylight saving time.
- `Columbus` exists in both Ohio and Georgia, so city lookups must match on state too.
- A few rows have no city, and many have gaps in the weather columns.
- About 30% of times carry the `.000000000` fraction that the 2023 release writes.

IDs start with `SYN-`, so they never collide with real dataset IDs (`A-<n>`).

`pnpm data:seed` loads this file, and `docker compose up` loads it automatically.
